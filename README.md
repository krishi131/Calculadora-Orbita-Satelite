# 🛰️ Calculadora de Órbita Satelital - Morelia

> Proyecto 2 de mi portafolio para NASA Space Apps Challenge 2026 y Space Academy - Embajada USA

Este script calcula la velocidad y el periodo orbital de cualquier satélite usando las Leyes de Kepler y Mecánica Orbital.

### 🚀 ¿Qué hace?
Calcula usando datos reales de la NASA:
- Velocidad orbital necesaria para mantenerse en órbita
- Tiempo que tarda en dar una vuelta a la Tierra
- Número de órbitas por día

### 💻 Tecnologías
- Python
- Física Orbital (G, Masa de la Tierra)
- Ecuaciones de Kepler

### 📍 Ejemplo de uso
Para la Estación Espacial Internacional (ISS) a 400km sobre Morelia:
- Velocidad: 7.67 km/s
- Periodo: 92.5 minutos
